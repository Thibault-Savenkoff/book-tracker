# VCS

## Setup

- Main branch: `main`
- Platform: GitHub, `Thibault-Savenkoff/book-tracker`
- Ticketing: none

## Branches

- Work happens directly on `main`. No branch naming convention is in use, and there are no pull requests.

## Commits

- History is machine-generated: an auto-sync tool commits `WIP: auto-sync <date> <time>` on a timer. The log is a backup trail, not a readable history.
- Commits written by hand should be conventional-commit style (`type(scope): description`, imperative, lowercase) to stand out from the auto-sync noise.
